Secure Task Manager

A REST API that actually protects your data.

Built as a hands-on security project: every user sees only their own tasks, enforced at the database query level - not just hidden in the UI. Passwords are BCrypt-hashed, sessions are stateless JWTs, and admins are bootstrapped from environment variables, never a self-service "make me admin" button.

Java 21 Spring Boot 3 Spring Security 6 + JWT PostgreSQL Docker OWASP-aware

Local dev admin (from .env defaults): admin@example.com / AdminPass123!
